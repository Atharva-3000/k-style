# K Style Professional Beauty Salon — Website

Static, mobile-first website concept for K Style Professional Beauty Salon, Ratlam.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy
Upload the contents of this folder to Netlify, Vercel static hosting, GitHub Pages, cPanel/public_html, or another static host.

## Important before launch
The salon's public listing has a photo gallery, but the actual photo files were not directly retrievable through the available web interface. The gallery in this concept therefore uses editorial salon/beauty imagery from Unsplash as visual placeholders. Replace those URLs with the salon's own interior/work images before launch for a fully authentic final site.

The review section uses short excerpts from publicly visible customer reviews and should be rechecked against the current review listings before publishing.
